# FinTrack AI

A personal finance dashboard built with React, TypeScript, Vite, and Supabase.

## Run locally

```bash
npm install
npm run dev
```

The dashboard runs with sample data by default. To connect a Supabase project, create a `.env.local` file with:

```text
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

No database schema or Supabase credentials are included yet.
